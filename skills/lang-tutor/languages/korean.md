# Korean Tutor Guide

Read this together with `_common.md`, which defines the feedback block formats, the universal deep-dive types, and the baseline level tables. This file supplies what is specific to Korean.

## Conventions

At beginner level, include Revised Romanization for all Korean text. Default to polite 해요체 (-yo) speech level in translations unless the user is practicing another level.

## Framework Alignment: TOPIK

Korean proficiency is standardized by TOPIK (Test of Proficiency in Korean), administered by NIIED. It runs as two exams covering six levels:

| Guide level | TOPIK | ≈ CEFR | Can-do target |
|---|---|---|---|
| Beginner | TOPIK I, levels 1-2 | A1-A2 | ~800-1500 words; survival conversation, self-introduction, daily routine in 해요체 |
| Intermediate | TOPIK II, levels 3-4 | B1-B2 | ~3000-4000 words; social and workplace situations, opinion, news with effort |
| Advanced | TOPIK II, levels 5-6 | C1-C2 | ~5000-10000 words; professional and academic register, formal writing, nuance and idiom |

## Grammar Syllabus

The standard TOPIK teaching sequence. Within each level, earlier items are foundational and should be taught before later ones. This drives both the Grammar Corrections priority in Mode 1 and the Concept Spotlight in Mode 2.

- **Beginner (levels 1-2)**: 한글 → 이에요/예요 and 입니다 → topic 은/는 vs. subject 이/가 → object 을/를 → location 에/에서 → SOV word order → 해요체 conjugation → past 았/었 → future 을 거예요 → negation 안 vs. 못 → the two number systems and basic counters
- **Intermediate (levels 3-4)**: connectives -아서/-어서 vs. -(으)니까 (cause), -는데 (contrast/setup), -(으)면 (condition) → honorific infix -시- → verb modifiers -는 / -(으)ㄴ / -(으)ㄹ turning clauses into adjectives → auxiliary verbs -아/어 보다, -아/어 주다, -고 있다 → indirect speech -다고/-냐고/-자고 → -기 and -(으)ㅁ nominalization
- **Advanced (levels 5-6)**: 합니다체 formal register → full honorific system including 드리다/주시다 and humble forms → written vs. spoken style → 한자어 (Sino-Korean) academic vocabulary → nuanced endings -더라, -길래, -더니 → idiom and proverbs

Add this row to both level tables in `_common.md`:

| Aspect | Beginner (TOPIK 1-2) | Intermediate (TOPIK 3-4) | Advanced (TOPIK 5-6) |
|---|---|---|---|
| Grammar focus (TOPIK) | 한글, 이에요/예요, particles, SOV, 해요체, past/future, 안/못, number systems | connectives, -시- honorific, verb modifiers, auxiliary verbs, indirect speech, nominalization | 합니다체, full honorifics, written style, 한자어, nuanced endings, idiom |

## Irregulars to Prioritize

Feeds the Irregularity Watch in `_common.md`. Korean irregularity is unusually tidy — nearly all of it is **class** irregularity keyed to the final consonant of the stem, so name the class and the learner gets a whole group.

**Class irregular** — teach the class, not the word:

| Class | Change | Example | Also |
|---|---|---|---|
| **ㅂ** | ㅂ → 우 before a vowel | 덥다 → 더워요 | 춥다, 쉽다, 어렵다, 아름답다 |
| **ㄷ** | ㄷ → ㄹ before a vowel | 듣다 → 들어요 | 걷다, 묻다, 싣다 |
| **ㅅ** | ㅅ drops before a vowel | 짓다 → 지어요 | 낫다, 붓다, 잇다 |
| **르** | 르 → ㄹㄹ | 모르다 → 몰라요 | 빠르다, 다르다, 부르다 |
| **ㅎ** | ㅎ drops, vowel contracts | 그렇다 → 그래요 | 파랗다, 어떻다, 이렇다 |
| **으** | 으 drops before a vowel | 쓰다 → 써요 | 바쁘다, 예쁘다, 크다 |
| **ㄹ** | ㄹ drops before ㄴ, ㅂ, ㅅ | 살다 → 삽니다, 사는 | 알다, 만들다, 놀다 |

**Locally irregular** — name where it's safe:
- Each class above misbehaves only in **specific phonetic environments** — before a vowel, or before ㄴ/ㅂ/ㅅ. Elsewhere the verb is perfectly regular. Say which environment triggers it rather than labelling the whole verb irregular.
- Crucially, **not every stem ending in these consonants is irregular**: 좁다 and 입다 are regular ㅂ-final verbs; 받다 and 믿다 are regular ㄷ-final. Membership must be learned per verb — flag it when a new verb enters the Key Vocabulary.

**Fully irregular** — must be memorized:
- **Honorific suppletion**: the honorific form replaces the verb outright rather than adding -시- — 먹다/마시다 → 드시다, 자다 → 주무시다, 있다 → 계시다, 말하다 → 말씀하시다, 죽다 → 돌아가시다. Treat as separate vocabulary.
- **Humble forms**: 주다 → 드리다, 보다 → 뵙다, 묻다 → 여쭙다
- **Two number systems**: native Korean (하나, 둘, 셋…) for counting objects, age, and hours; Sino-Korean (일, 이, 삼…) for dates, money, minutes, and phone numbers. The native numbers also truncate before counters — 하나 → 한 개, 둘 → 두 개, 셋 → 세 개.

**By level**: at TOPIK 1-2 prioritize the ㅂ, 으, and 르 classes and the number systems; at 3-4 the remaining consonant classes and honorific suppletion; at 5-6 humble forms and register-bound vocabulary pairs.

## Error Categories to Watch For

In Mode 1 Grammar Corrections, prioritize: particle choice (은/는 vs. 이/가, 을/를 dropped or misplaced), speech-level consistency (mixing 반말 and 해요체), irregular verb conjugation (ㅂ, ㄷ, 르 classes), native vs. Sino-Korean numbers with counters, word order before the final verb.

Flag speech-level mismatches — register matters as much as grammar in Korean.

## Watch-outs

- **은/는 vs. 이/가**: the perennial particle confusion — correct it every time with a one-line topic-vs-subject reminder
- **Speech-level mixing**: 반말 endings sliding into a polite sentence read as jarring — flag even when grammar is otherwise fine
- **Two number systems**: native Korean numbers for counting objects/age, Sino-Korean for dates/money/minutes — correct mismatches with the counter
- **Subject dropping**: Korean drops subjects English speakers feel compelled to include — show the dropped-subject version as the natural alternative
- **Irregular verbs**: ㅂ-irregular (덥다 → 더워요), 르-irregular (모르다 → 몰라요) — name the pattern when correcting, not just the form
- **Honorifics apply to the subject, not the listener**: using -시- for yourself is a common and socially awkward error — flag it directly
- **-아서 vs. -(으)니까**: both mean "because," but only -(으)니까 can precede a command or suggestion — name the constraint when correcting
